🚀 **AI Document Intelligence System | RAG + LLMs**

I’m excited to share my **AI Document Intelligence System**, a project designed to make working with PDF documents smarter, faster, and more efficient.

The system leverages Large Language Models (LLMs) and Retrieval-Augmented Generation (RAG) to help users interact with their documents and extract meaningful information.

✨ **Key Features:**

* 📄 PDF document processing and text extraction.
* 🧠 AI-powered document analysis with structured outputs.
* 💬 Question answering based on document content.
* 📝 Automated document summarization.
* ⚖️ Document comparison to identify key differences.
* 📚 Source references to help users trace information back to the document.

🛠️ **Tech Stack:**
Python, LangChain, Groq API, Hugging Face Embeddings, FAISS, Pydantic, FastAPI, Streamlit, and PyPDF.

This project helped me gain hands-on experience integrating LLMs, building RAG pipelines, working with structured AI outputs, and connecting an AI backend to an interactive web interface.

I’m continuing to improve the system and explore more ways to build practical AI-powered applications.
